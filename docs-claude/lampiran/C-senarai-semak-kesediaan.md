## C4 — Semakan Selepas Go-Live

Dijalankan pada hari ketiga, minggu kedua, dan bulan pertama selepas setiap go-live.

| Perkara disemak | Hari 3 | Minggu 2 | Bulan 1 |
|---|---|---|---|
| Bilangan tiket sokongan daripada pengguna | | | |
| Tiga aduan paling kerap | | | |
| Kadar penggunaan sistem berbanding kaedah lama | | | |
| Masa tindak balas purata sistem | | | |
| Kadar kegagalan penghantaran e-mel | | | |
| Ralat pelayan yang direkod | | | |
| Ruang cakera dan pertumbuhan pangkalan data | | | |
| Kecacatan baharu ditemui | | | |
| Maklum balas kualitatif daripada juara pengguna | | | |

**Tindakan jika kadar penggunaan rendah pada minggu kedua.** Jangan andaikan pengguna memerlukan lebih latihan. Temu bual lima pengguna yang tidak menggunakan sistem dan tanya apa yang menghalang mereka. Punca biasanya adalah satu langkah yang menyusahkan dalam aliran kerja, bukan kekurangan pengetahuan.
